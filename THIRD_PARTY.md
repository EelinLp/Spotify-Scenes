# Компоненты и ресурсы

- **Spicetify CLI 2.46.4** — LGPL-2.1. Официальные компоненты находятся в `vendor/spicetify`; лицензия и полный архив исходников соответствующей версии включены в `licenses/`. Проект: https://github.com/spicetify/cli/releases/tag/v2.46.4
- **Фоны** созданы для исходного проекта средствами генерации изображений. Описание и происхождение — `licenses/BACKGROUND-ASSETS.md`. Они включены вместе с исходниками оформления.
- **Comfortaa, Unbounded, Jura, Russo One, Golos Text, Rubik** — соответствующие OFL-файлы в `licenses/`.
- **Эффекты** адаптированы из исходного проекта оформления Яндекс Музыки с сохранением MIT-уведомления Markus.
- **Иконка Могити** предоставлена владельцем проекта. Отдельная исходная лицензия изображения не указана; лицензия MIT на код не объявляется лицензией этого изображения.
- Модель Верити, её геометрия, выражения лица и анимации создаются кодом WebGL в `src/verity-3d.js`, без внешних моделей и библиотек.

Клиент Spotify и пользовательские данные не входят в дистрибутив.
