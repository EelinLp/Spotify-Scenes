# Spotify Scenes

Оформление Spotify Desktop для Windows: фоны, эффекты, шрифты, компактный интерфейс и объёмный Верити вместо видеоряда.

[Скачать последнюю версию](https://github.com/EelinLp/Spotify-Scenes/releases/latest)

## Установка

1. Установи Spotify Desktop с [официального сайта](https://www.spotify.com/download/windows/) и войди в аккаунт.
2. Скачай `Spotify-Scenes-Setup-0.1.2.exe` из Releases.
3. Запусти установщик и нажми «Установить». Затем открой Spotify.

Установка выполняется для текущего пользователя без прав администратора. На время изменения файлов Spotify будет закрыт. Версия Spotify из Microsoft Store не поддерживается.

Spicetify 2.46.4 уже находится внутри установщика: отдельная установка и загрузка Spicetify не нужны. Поддерживаются пути Windows с кириллицей и пробелами. Перед первой установкой открой Spotify и войди в аккаунт.

Альтернатива: распакуй ZIP целиком и запусти `Install.cmd`.

## Если установка остановилась

Запускай установщик обычным двойным щелчком. Он не запрашивает права администратора. Если Windows уже запустила его с повышенными правами (включая встроенный профиль «Администратор»), для Spicetify автоматически используется штатный флаг `--bypass-admin`; установка по-прежнему затрагивает только Spotify текущего пользователя. Имена папок с кириллицей поддерживаются.

При ошибке в окне выводятся команда, ответ Spicetify и путь к подробному журналу. Общий журнал: `%LOCALAPPDATA%\SpotifyScenes\install-setup.log`. Если отсутствует файл Spotify `prefs`, сначала открой Spotify и войди в аккаунт, затем повтори установку.

## Возможности

- 8 встроенных фонов и своё изображение; затемнение, размытие и заполнение окна.
- 6 шрифтов с кириллицей и 8 эффектов, включая автоматический подбор эффекта под фон.
- Компактное меню, прозрачные списки, оформление поиска, любимых треков и радио.
- Синхронизированные строки песни при доступности текста в Spotify.
- Три режима блока на главной: видео/обложка, Верити 3D и скрытый видеоряд.
- Верити: 16 танцев, 10 эмоций, автоматическая смена, настройка скорости и реакция на паузу. Нажатие на персонажа меняет танец.
- Анимированная декоративная волна внизу главной.

Настройки находятся в шестерёнке слева. Параметры сохраняются отдельно для аккаунтов Spotify.

## Стандартные настройки

Нефритовый фон, Jura, заполнение окна, затемнение 35%, размытие 0, автоматические эффекты, плотность 100%, скорость эффектов 0.8×, компактное меню, Верити 3D, автоматические танцы и эмоции, скорость движений 1×. Полный набор — `src/defaults.json`. При обновлении уже сохранённые настройки не сбрасываются.

## Удаление

В списке установленных программ Windows выбери Spotify Scenes и нажми «Удалить». Для ZIP-установки запусти `Uninstall.cmd`. Восстанавливаются файлы Spotify до установки мода; сохранённые параметры оформления и резервные копии остаются.

## Совместимость

Проверено на Windows и Spotify Desktop **1.3.6.1921** со Spicetify **2.46.4**. Обновления Spotify могут менять его интерфейс; после обновления может потребоваться повторная установка или адаптация мода. Это оформление клиента: подписка, рекомендации, доступность видео и текстов остаются функциями Spotify. Точный битрейт потока мод не показывает.

Установщик не имеет цифровой подписи. Контрольные суммы файлов опубликованы в `SHA256SUMS.txt` релиза. В сборке нет пользовательских аккаунтов, истории прослушивания или личных настроек Spotify; включён только стандартный набор параметров самого мода.

## Сборка из исходников

Нужны Node.js 20+ и Windows с .NET Framework 4.7.2+.

```powershell
node tools/build.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-setup.ps1
```

Файлы появятся в `dist/`. Компилятор C# берётся из системного .NET Framework. Дополнительные npm-пакеты не нужны. Проверка содержимого установщика без установки: `Spotify-Scenes-Setup-0.1.2.exe --verify-package`.

## Скачивание музыки

Встроенное скачивание Spotify Premium доступно через кнопку загрузки плейлиста или альбома. Сохранённые треки предназначены для прослушивания внутри Spotify. Экспорт аудио в MP3/FLAC из мода Яндекс Музыки сюда не перенесён: он использует другой сервис и формат получения аудио.
